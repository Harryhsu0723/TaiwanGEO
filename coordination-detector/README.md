# Coordination Detector（Threads 政治貼文協同行為偵測）

研究用專案：分析 Threads 上政治貼文的留言，偵測**協同性不真實行為（Coordinated Inauthentic Behavior, CIB）**的統計跡象。

> 輸出的是「協同行為分數」與「帳號群集」，**不是**「某人是網軍」的判定。見 `docs/ETHICS.md`。
