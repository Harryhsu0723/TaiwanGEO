# 資料取得與合規

## 選項（建議由上而下）
1. **Meta Content Library / Content Library API**：Meta 提供給合格研究機構的公開內容研究工具，涵蓋 Facebook、Instagram，Threads 的涵蓋範圍須以申請時官方說明為準。需申請並通過審核。
2. **Threads API（官方）**：以授權使用者身分讀取自己的貼文與回覆；關鍵字搜尋與取得他人貼文留言的範圍受限，須查閱最新文件。
3. **研究者合作／既有資料集**：匯入 CSV/JSON，走同一 schema。
4. **自行爬取**：Threads 條款禁止未授權的自動化蒐集，且需登入、有反爬與速率限制，帳號與 IP 可能被封，亦有法律風險（條款、個資法）。**本專案預設不採用，若採用須先做法律評估並書面記錄。**

## 臺灣個資法考量
- 公開貼文仍可能含個資；研究使用需符合蒐集目的、最小化蒐集，並做匿名化。
- 不蒐集私人帳號、不蒐集受限內容。
- 保存期限與刪除流程須明訂。

## 技術原則
- collector 介面統一（`iter_posts()`, `iter_comments(post_id)`），來源可替換。
- 請求限速、可中斷續跑、保留抓取時間與來源版本。
