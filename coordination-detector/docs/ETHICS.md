# 倫理與風險

1. **不貼標籤**：輸出為群集層級的協同行為統計，不稱任何個人為「網軍」。公開報告禁止附可辨識的帳號 handle。
2. **誤判成本高**：真人動員、粉絲社群、迷因接龍都會產生高協同訊號。每個結論須附基準、不確定性與替代解釋。
3. **雙向對稱**：不同政治立場的資料以同一標準處理，避免選擇性分析。報告列出各立場的群集分數分布。
4. **資料最小化與匿名化**：帳號雜湊、salt 分離、保存期限、存取權限控管。
5. **防濫用**：工具不提供「指定帳號 → 身分還原」功能；不提供騷擾、人肉用途所需的輸出。
6. **透明**：方法、閾值、驗證結果公開；人工覆核流程須記錄。
7. **審查**：若隸屬研究機構，先經倫理審查（IRB/REC）。
